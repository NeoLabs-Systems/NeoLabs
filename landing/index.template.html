The seams

Each one makes the others better.

No required suite and no shared cloud. Run one, and connect the next when you want it.

The agent can read your day.

NeoAgent signs in with OAuth and gets seven read-only tools and three triggers. It can search your memories and can never change them.

The agent gets every model.

Connect NeoRouter for the whole server or for one person. Your agents stop depending on any single provider’s uptime.

Memory runs on any model.

NeoRecall works with any OpenAI-compatible transcription and language service, so NeoRouter’s endpoint can supply both.

Prefer your own tools? Paste NeoRecall’s MCP URL into Claude, ChatGPT or Cursor for read-only recall.

Boundaries

Promises, written in code.

NeoAgent

Asks, then acts.

Approval before risky actions, per-tool permissions and read-only integrations. Every step lands in a log you can inspect or stop.

NeoAgent

Logins the model never sees.

Bitwarden credentials stay out of the model’s reach.

NeoRecall

No covert mode.

A recording notice and a persistent recording state, always.

NeoRecall

Deletion is a protocol, not a promise.

Clients hold every audio chunk until a terminal receipt proves the transcript is durable and the server copy is gone.

NeoRouter

Free means free.

Free-only keys never touch a paid model. Budgets stop paid keys at the limit you set, per day, month or in total.

NeoRouter

Prompts stay out of the logs.

Only request metadata is logged. Provider keys stay encrypted and private per account.
